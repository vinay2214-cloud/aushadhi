# AUSHADHI Frontend

Autonomous Medicine Supply Intelligence Dashboard

Built with React 19, TanStack Start, Tailwind CSS v4, and Bun.

## Setup

```bash
bun install
cp .env.example .env.local
# Set VITE_API_BASE_URL and VITE_API_KEY
bun run dev
```

## Production

```bash
bun run build
```

See the main [README.md](../README.md) for full project documentation.
